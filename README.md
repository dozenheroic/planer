**скачать проект**
```powershell
git clone https://github.com/dozenheroic/planer.git
```
**перейти в папку проекта**
```powershell
cd planer
```
**создать виртуальное окружение**
```powershell
python -m venv venv
```

**сктивировать виртуальное окружение**
```powershell
.\venv\Scripts\Activate.ps1
```

**установить Flask**
```powershell
python -m pip install flask
```

**запустить приложение**
```powershell
python app.py
```

http://127.0.0.1:5000

**проверка базы данных**

```powershell
python check_database.py
```
